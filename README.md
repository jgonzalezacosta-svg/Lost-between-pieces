# Lost-between-pieces
Lost Between Pieces es una novela visual de terror y misterio creada en Ren’Py por Caterina Teruggi, Joaquín Gonzalez y Melany Cantero, como proyecto de Laboratorio de Programación de 6.º 4.ª. Acompañá a Ellie en una investigación llena de secretos, enigmas y decisiones que determinarán su destino.
